## 二、已完成的事（按主题）

### 1. 首次访问链路（登录）——「需要异步行为」的四个环节补齐

- 元素级原语 `AsyncActionLabel`：挂起态与常态之间「旧标签先退 80ms → 新标签延迟进 160ms」；
- 欢迎页三段错峰入场 + 两个入口按压反馈；**隐藏**两句定位说明（资源保留）；
- 发起授权有独立挂起态 `oauthBusy`（连点不再开两个浏览器标签页）；
- 授权中页：「返回上一页」（回**授权登录介绍页**）+「重新打开授权页」，两个半宽按钮；
- 失败页：`failedAt` 必填 + `classifyOAuthFailure`（凭据 / 过期码 / 回调地址）→ 可行动文案；
- 密钥校验：整屏覆盖加载（`LoginBusyOverlay`），失败留在本页；
- 登录成功进主界面：嵌套 `PageSwitcher`（`GateRoute`），退场旧页放手返回键；
- 介绍页：底部双按钮（左换方式、右主操作）、副标题/脚注不渲染、GitHub 图标 + 中英双语文档抽屉。

### 2. 文案与语言

- 登录链路全部资源化（`AuthFlowStep` 改 `@StringRes`），`LoginScreens.kt` 进 `I18nUiTextTest` 清单；
- `README.md` 改为**英文展示页**（8 枚徽章），中文权威版保留为 `README.zh.md`；
- 发布页正文**英文段在前**（固定展示文案），中文改动记录在后（权威）；
- CI 门禁 `check-i18n.py --min-coverage 100` 一直保持通过。

### 3. 构建与发布

- **四渠道**：`com.branchbase`（release 签名 / beta 签名）、`com.branchbase.dev`、`com.branchbase.test`
  （`dev`/`trial` build type；`test` 前缀被 AGP 保留，内部叫 `trial`）；
- **矩阵编译**：`version → core(.so artifact) → build[debug/dev/trial/perfBeta] → publish`，
  每条腿一个 Gradle 进程；`.so` 缓存 key 只含 `core/**` 哈希；
- **CI 拆分**：`ci.yml`（android 主变体 + 单测 / android-variants 矩阵 / rust check·test·clippy），
  原 `build-core.yml` 并入后删除；
- **正式版四渠道**：`build-release.yml` 增加 `channels` 矩阵，发布 5 APK + 双签名 + 源码；
- **签名指纹现算**：`apksigner verify --print-certs` + 抽 64 位十六进制（不钉输出前缀）；
- **Pages**：`site/` + `pages.yml`，已启用：<https://sunsetrne.github.io/Branchbase-Android/>。

### 4. 日志

- `ExitScenario` + `classifyExit(reason, importance, description)`：13 类场景，
  级别/标签/措辞跟场景走。真机那条 `原因码 13 + 后台缓存 400 + o-kill(4010)` 不再记成

- 只有闪退 / native 崩溃 / ANR 算事故（`ERROR`，标签「异常退出」）。

## 三、踩过的坑（环境 / 工程）

| 坑 | 现象 | 结论 |
|---|---|---|
| 本机 Gradle 8.10.2 ≠ AGP 9 要求 | 直接 `gradle` 失败 | 用仓库 wrapper（9.1.0）并经**同一个构建槽**跑 |
| 中文测试方法名 | `NoClassDefFoundError` / `wrong name` | 必须 `LANG=C.UTF-8`；清掉错编码的测试类再用 `--no-build-cache` 重编 |
| `main` 不留 `.so` | 本地 APK 装上即闪退（`UnsatisfiedLinkError`） | 打包任务已加护栏；`tools/build/fetch-core.sh` 一键取同 commit 产物 |
| AGP 保留 `test` 前缀 | `BuildType names cannot start with 'test'` | test 渠道内部 build type 叫 `trial`，对外仍是 `.test` |
| build-tools 37 改了 apksigner 输出 | CI 指纹为空 | 不钉前缀，抽 64 位十六进制 |
| 四渠道同进程编译 | Compose 代码生成 `OutOfMemory` | 拆矩阵，每条腿一个进程（加堆没用） |
| `/design/` 历史原型未迁入 | 设计稿钉子必红 | 用 `Assume` 跳过，迁入后自动生效 |
