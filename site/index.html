What it does功能

Sign-in登录

OAuth (code + PKCE) or a personal access token; multiple accounts. OAuth（code + PKCE）或个人访问令牌；支持多账号。

Browse浏览

Repositories, README rendering, languages, contributors, search, notifications. 仓库、README 渲染、语言统计、贡献者、搜索、通知。

Write写入

Three commit modes, libgit2 clone / pull / commit / push, PR · issue · release flows. 三种提交模式，libgit2 克隆 / 拉取 / 提交 / 推送，PR · Issue · Release 流程。

Extras扩展

Resumable downloader, image viewer, code editor, immersive translation, job logs. 断点续传下载器、图片查看器、代码编辑器、沉浸式翻译、Job 日志。

Links链接

English first, Chinese authoritative — docs/specs/ is maintained first and wins where the two differ. 英文优先，中文权威 —— 文档先以中文维护，两者冲突时以中文为准。
