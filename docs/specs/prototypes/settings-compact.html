方案说明

    

      

        
A · 只删说明

        下线解释性 sub 与 SettingsProse，行高、卡片底、字号都不动。

        风险最低：只删文案，命中区与视觉语言完全不变。
      

      

        
B · 删说明 + 压密度

        A + SettingsDensity.Compact（行 44dp / 图标 18dp / 卡底 Gray100）。

        视觉变化最大：命中区从 48 → 44dp，需要真机复核误触。
      

      

        
C · 重组 IA

        B + 控件换型（10 档单选 → 分段/下拉）、重复信息合并、说明搬进页内折叠。

        收益最大、风险最高：要改交互与文案，必须过一轮原型。

决策与边界

    

      

        
这一轮改了什么

        
    
          
  • 主页一行一个入口，说明文字全部下线（206 字 → 0）
    • 
          
  • 账户卡 → 「账号管理」入口（不再渲染头像 / 登录名 / 胶囊）
    • 
          
  • 行 48→44dp、图标 20→18dp、内边距 16→14dp、分组 6→4dp
    • 
          
  • 卡片底 BackgroundSecondary → Gray100，并去掉纯黑描边（真机反馈「取消掉黑边」）
    • 
          
  • 「通知」组去掉组标签：组名与行名重复（规范 §3.2）
    • 
          
  • 主题从三档分段改成入口行，三档与悬浮玻璃导航栏收进主题页（1.4.40，规范 §十七）
    • 
          
  • 玻璃导航说明按状态说话：关 / 开两句（16 / 15 字），独占整行宽 + 12sp（1.4.43）
    • 
          
  • 翻译页压密：八组卡片化 + Compact，行内说明压到 ≤22 字，570 字说明改页头「!」弹窗（1.4.44，规范 §十八）
    • 
          
  • 主页删掉「自动翻译正文」开关：总开关只在翻译页（同上；modules-design.md §1「开启入口只有一个」）
    • 
          
  • 翻译页第二改（1.4.45，规范 §十九）：说明弹窗加可拖滚动条、凭据块弹簧折叠 + 40dp 输入框、模型行「获取模型列表」+ 弹性勾选弹窗 + 二次隐私确认后落盘
    • 
          
  • 凭据块 28dp 输入框（1.4.48）：标签在框上方、值 13sp/16sp 行高，修「光标上偏」（占位符与输入行统一行盒）
    • 
          
  • 模型选择 UX（1.4.49）：默认模型预填、保存列表取首个、芯片选中底色 + 逐字输入、绿色「当前」徽标；保存与「测试响应」拆开（测试只探端点）
    • 
          
  • 保存成功反馈（1.4.50）：弹簧曲线覆盖弹窗，绿勾 +「已保存到本机」，约 1.8s 自动消失
    • 
        

      

      

        
没改什么

        
    
          
  • 二级页的尺寸与排版：仍走 SettingsDensity.Comfort（翻译页是第一个例外，见 1.4.44）
    • 
          
  • 行型仍是封闭集合里的 5 种（NavRow / SwitchRow / ChoiceRow / DangerRow / DisabledNavRow）
    • 
          
  • 值列保留：跟随系统 / 单次提交 / 未设置 / 已开启 —— 它们是值不是说明
    • 
          
  • 禁用行的原因（规范 §6.3 强制）与危险行确认（§7.2）
    • 
          
  • 主题三档分段（§5.2）、通知用导航行 + 胶囊（§4.3）
    • 
        

      

      

        
风险

        
    
          
  • 44dp < Material 48dp：仍 ≥ WCAG 2.5.5 / iOS 44pt。误触就把 Compact.rowMinHeight 调回 46–48（一处改）
    • 
          
  • 账户异常（令牌失效）不再第一屏可见 → 将来若恢复，挂状态胶囊，不搬回身份卡
    • 
          
  • 200% 字号未验：单行名称只会把行撑高，不会挤掉值列
    •
