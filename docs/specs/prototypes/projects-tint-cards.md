# 项目列表 · 卡片面 + 图标牌 · 设计说明

> 原型：[`design/projects-tint-cards/index.html`](../../../design/projects-tint-cards/index.html)
> 状态：**待确认**（当前账号没建过项目，实机只能看到空态）

## 一、怎么打开

侧边栏「原型预览」打开。工具条两组：**主题**（浅 / 深）、**状态**（有项目 / 空态 / 加载中）。

## 二、为什么要先出原型

`ProjectsScreen` 现在只有「加载中 / 空态 / 列表」三条路径，而列表项是**裸文字**
（名字 + 描述，无卡片）。要把它接到「卡片面 + 图标语义三色」，得先回答两件实机上问不出来的事：

1. 没写描述的项目（`description == null`）在卡片里长什么样；
2. 超长描述在 2 行截断下，卡片高度是否稳定。

## 三、提案

| 项 | 值 | 说明 |
|---|---|---|
| 卡片 | `cardSurface()`（白面 + 4dp 阴影、12dp 圆角） | 与首页仓库卡 / 设置卡同一套 |
| 卡距 | 6dp | 与仓库卡一致 |
| 内边距 | h12 · v8 | 比仓库卡的 h14 略紧：项目卡只有两行文本 |
| 图标牌 | 22dp / 7dp / 13dp，`TintRole.DONE` | 与 More 菜单的「项目」同色（紫） |
| 名字 | 14sp / SemiBold / `TextPrimary` | 单行省略 |
| 描述 | 12sp / 行高 15sp / 限 2 行 | 与仓库卡同一条规则 |
| 无描述 | 灰字「暂无描述」（不省略行） | 卡片节奏不断档，也不会矮一截 |
